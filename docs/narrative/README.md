## Fixed by the PRD

**Central message (§6)** — suggested, refinable during branding/copywriting:

> Conectamos sistemas. Automatizamos processos. Construímos soluções.

Complementary:

> Tecnologia aplicada aos desafios reais das empresas.

**Home sequence (§11.2):**

```text
Navbar → Hero → Problema → Posicionamento → Soluções → Como trabalhamos
       → Projetos → Diferenciais → CTA → Footer
```

**Problem framing (§13):**

> Sua empresa já tem tecnologia. O problema é quando ela não conversa.

Recognisable situations: disconnected systems, manual processes, duplicated
data, scattered information, repetitive tasks, tools that do not meet specific
needs.

**Process (§15)** — five steps: Entendemos → Desenhamos → Construímos →
Integramos → Evoluímos. The site must **not** claim every project passes
through all five.

**Primary CTA (§29):** *Fale com a PXTO*. Contextual alternatives: *Vamos
conversar*, *Conte seu projeto*, *Quero conversar sobre meu projeto*, *Começar
uma conversa*. Avoid "Saiba mais" as a primary CTA, "Clique aqui", and
"Solicite agora" where no request process exists.

**Final directive (§57):** PXTO must read as a company that solves problems
through technology, not one that sells technical services. Integrations,
automation, software, AI and websites are tools inside that proposition.
