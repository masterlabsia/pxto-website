# Definition of Done

From PRD §49. A page or feature is not done until every applicable box is
checked.

## Content

- [ ] Copy reviewed
- [ ] Links working
- [ ] CTA defined
- [ ] SEO configured

## Design

- [ ] Design System respected
- [ ] Desktop validated
- [ ] Mobile validated
- [ ] States defined

## Development

- [ ] TypeScript with no errors
- [ ] Lint with no errors
- [ ] Build working
- [ ] Components reusable
- [ ] No unnecessary duplicated code

## QA

- [ ] Links tested
- [ ] Forms tested
- [ ] Responsiveness tested
- [ ] Navigation tested
- [ ] Console free of critical errors
- [ ] Performance reviewed
- [ ] Accessibility reviewed

---

## Website acceptance criteria (PRD §50)

The website is ready when:

1. All planned pages are implemented.
2. The narrative is consistent.
3. PXTO's positioning is clear.
4. All four solutions are presented.
5. Existing projects are published consistently.
6. New projects can be added through the defined framework.
7. The website is responsive.
8. The website is accessible.
9. Technical SEO is configured.
10. The form works.
11. Analytics is configured.
12. Performance is validated.
13. There are no critical console or build errors.
14. The website is published at `pxto.co`.
15. The website can be maintained and evolved without rebuilding the
    architecture.
